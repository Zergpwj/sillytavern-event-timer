# 配置档案 · 提示词库 · 历法月名 · AI 推断

这篇讲四个「让插件适配你的世界」的功能。都在 **扩展 → 计时器** 的设置面板里。

---

## 1. 配置档案：换角色卡不再失效

### 问题

只有一个全局设置时：你为 A 角色调好了日历制、起始时间、自定义提示词，
一切到 B 角色，这套设置要么被 B 的改动覆盖，要么和 B 的世界观完全不搭。

### 做法

**每个角色卡 / 群聊可以绑定一份「档案」，切换对话时自动套用。**

设置面板 → **配置档案（按角色卡自动切换）**：

```
当前角色：爱丽丝
当前生效：爱丽丝的世界
当前配置 [ 爱丽丝的世界 ▾ ]
[为当前角色新建档案] [绑定当前角色到本档案] [解绑当前角色] [重命名…] [删除]
```

推荐流程：

1. 打开角色卡 A，把时间制式、历法、起始时间、提示词都调好；
2. 点 **「为当前角色新建档案」**，起个名字（默认就是角色名）；
3. 切换角色卡 B → 插件自动切到 **「全局默认」** 档案；
4. 在 B 上调好之后，同样点「为当前角色新建档案」。

### 关于「全局默认」

档案列表里有一项内置的 **「全局默认」**：

- **所有没有绑定档案的角色卡 / 群聊都用它**；
- 它不能被删除、不能改名；
- 它是一份普通档案，你可以在下拉框里选中它、然后像改别的设置一样改它。

> ⚠ **一个容易踩的点**：当你停在「全局默认」上改设置时，改的就是全局默认本身
> —— 所有未绑定的角色都会跟着变。设置面板在你处于这个状态、且当前有打开角色卡时
> 会显示一行橙色提示。想只影响当前角色，就先点「为当前角色新建档案」。

### 绑定关系存在哪

绑定的键是**稳定标识**，不是角色名（角色名会被改）：

| 情况 | 键 |
| --- | --- |
| 单角色 | `char:<角色卡文件名>`，例如 `char:alice.png` |
| 群聊 | `group:<群聊 id>` |
| 通用宿主（非酒馆） | `chat:<对话键>` |

档案、绑定关系、提示词库都保存在酒馆的 `extension_settings.story_timer` 里（全局设置），
而**每场聊天的倒计时状态**仍然存在 `chat_metadata.story_timer`（跟着聊天走）。

## 2. 提示词库：注入的文案可以改、可以存、可以改名

设置面板 → **提示词库**：

```
当前使用  [ 默认提示词（内置） ▾ ]
[编辑] [另存为…] [重命名…] [删除] [新建空白]
▸ 预览当前会注入的文案
```

- **五段文案打开就是满的**：协议说明 + 四个时点，空字段会在启动时自动补成内置文案。
  点开编辑器看到的就是**当前实际会用到的文字**，直接在原文上改即可；
- 点 **编辑** 打开编辑器，改完保存即生效；编辑器底部有**实时预览**，
  用示例事件展示这份文字真正发出去长什么样（四个时点各一段）；
- 点 **另存为…** 复制一份出来改，原来那份不受影响；
- **重命名 / 删除** 对你自己的副本可用；「默认提示词」不能改名也不能删（防止把自己搞丢）；
- 每一段旁边都有 **「恢复内置文案」**，改坏了随时点回来；
  **「清空」** 之后仍然会自动套用内置。

### 支持的占位符

「记录格式说明」里可以用：

| 占位符 | 替换成 |
| --- | --- |
| `{{tag}}` / `{{tags}}` | 第一个标签名 / 全部标签名（逗号分隔） |
| `{{timeClock}}` | **当前剧情时间**（会随剧情走，别写死具体时间） |
| `{{dayLabel}}` | 计数制的日期标签，例如 `第3天` |
| `{{exampleClock}}` | 当前制式下的示例时间，例如 `第3天 14:30` 或 `1247年3月15日 14:30` |
| `{{timeMode}}` | `计数制` / `日历制` |
| `{{era}}` | 纪元前缀 |
| `{{monthCount}}` / `{{monthNames}}` | 月份数量 / 月名列表 |
| `{{tooShort}}` | 「时长门槛」那句话，例如 `少于6小时的事不要写` |
| `{{reminderHint}}` | 「事件+ 只在开始时写一次就够了……计时器会在后续时间点提醒你」那句 |
| `{{protocol}}` | 内置生成的完整文案（想在内置文案前后加点东西时很有用） |
| `{{header}}` | `[计时器·剧情时间提醒]` |

「提醒模板」里可以用 `{{time}}`（当前剧情时间）、`{{events}}`（事件清单，
**已经带好编号**）、`{{count}}`（事件数）、`{{tag}}`，以及 `{{overdueHint}}`
（到点时若有事件已超时才出现，否则整行消失）。

> **补全之后存的是「模板」，不是当时的文字。**
>
> 这一点很关键：协议里有「当前剧情时间」这种**活的值**。如果提示词库里
> 存的是渲染好的文本，那个时间就被冻在保存的那一刻了 —— 模型会一直看到
> 旧时间，甚至照着它写，时钟就卡住不动了。
>
> 存模板则不会：`{{tag}}`、`{{timeClock}}`、`{{tooShort}}` 这些在真正发出去的
> 时候才代换，所以你之后改标签名、改时长门槛，它都跟着变。
>
> 代价是：**插件本身升级了内置文案，你手里这份不会自动跟着变** ——
> 点一下那一段的「恢复内置文案」就能拿到最新的。

### 从旧版本迁移

老版本用的是「提醒策略 → 查看/编辑标签协议说明」里的 `protocolTemplate`。
升级后第一次启动时，如果那里有内容，会自动迁移成一条名为
**「我的提示词（从旧设置迁移）」** 的提示词并设为使用中。原字段会清空，不会重复迁移。

## 3. 自定义月名：AI 可以直接写「春月」

设置面板 → **时间基准 → 自定义月名 → 编辑月名…**

```
┌ 编辑月名 ─────────────────────────────────┐
│ 当前历法有 12 个月。给每个月起名字…        │
│ 第1月[春月] 第2月[花月] 第3月[风月] …      │
│ ── 批量导入 ──                             │
│ [春月, 花月、风月\n夏月 炎月 雨月 …]        │
│ [导入到上面] [用「一月、二月…」填充] [清空] │
└───────────────────────────────────────────┘
```

批量导入支持用 **换行 / 逗号 / 顿号 / 竖线 / 斜杠 / 空格** 分隔，按顺序覆盖。

### 月名参与**解析**，不只是显示

配好月名之后，AI 可以直接写：

```
时间: 1247年霜月7日 09:00
事件+: 赶路 | 2个月
```

- `1247年霜月7日` → 第 8 个月的第 7 天；
- `春月3日`（不写年份）→ 用当前年份；
- `寒月`（不写日）→ 该月 1 号；
- 正文里写「到了霜月7日，……」也能被正则兜底识别；
- 「2个月」按真实月份加，从霜月往后 2 个月就是冬月。

### 显示格式会自动跟上

如果你配了月名，但「日期格式」还是 `{era}{year}年{month}月{day}日`，
会显示成 `帝国历1247年8月7日`——**月名白配了**。

所以保存月名时，插件会自动把格式里的 `{month}月` 换成 `{monthName}`
（只在你还没手动改过格式时做）。你也可以在设置里手动改：

| 占位符 | 含义 |
| --- | --- |
| `{era}` | 纪元前缀 |
| `{year}` `{month}` `{day}` | 数字年月日 |
| `{monthName}` | 该月的名字 |
| `{daySuffix}` | 「日」/「号」之类 |
| `{hour}` `{minute}` | 补零的时分，例如 `09` `05` |
| `{time}` | 等价于 `{hour}:{minute}` |

例：`{era}{year}年{monthName}{day}日` → `帝国历1247年霜月7日`
例：`{year}-{month}-{day} {hour}:{minute}` → `2023-5-12 21:32`

**写了时间占位符，就不会再自动追加时分**；没写的话，插件会在日期后面补一个 `HH:MM`。
换句话说这两种写法结果一样：

```
{year}年{month}月{day}日              → 2023年5月12日 21:32
{year}年{month}月{day}日 {hour}:{minute} → 2023年5月12日 21:32
```

> `HH:mm` / `H:i` 这种**字面量**写法也会在保存时自动换成 `{hour}:{minute}`，
> 所以你在设置里随手写 `2023-05-12 HH:mm` 也能用。
> 不认识的占位符（比如 `{weekday}` 之外的 `{oops}`）会**原样输出**，方便你一眼看出写错了。

> 英文月名里有空格的（`Frost Moon`）不要用批量导入，直接在上面的格子里逐月填。

## 4. 用 AI 推断历法

设置面板 → 时间基准 → **AI 推断历法**

向导会：

1. 按你勾选的来源（**世界书条目 / 角色卡设定 / 最近对话 / 用户人设**）收集线索；
2. 拼成一段带 JSON 形状说明的提示词，发给模型；
3. 解析模型返回的 JSON，给出预览；
4. 你勾选要套用哪些字段，点「套用结果」。

### 两个后端

| 后端 | 说明 |
| --- | --- |
| **酒馆主 API** | 走 `generateQuietPrompt`。不写聊天记录、不触发世界书扫描，最省事。 |
| **自定义 API** | 自己填 `Base URL` / `API Key` / `模型名`，走 OpenAI 兼容的 `/chat/completions`。适合用便宜的模型专门干这活，或者你不在酒馆里跑。 |

接口地址会自动补全：`https://api.openai.com` → `https://api.openai.com/v1/chat/completions`。
API Key 只存在本地设置里。

### 世界书线索的读取范围

出于安全和性能考虑，**默认只读「当前聊天绑定的世界书」和「角色卡绑定的世界书」**，
不会去翻你的整个世界书目录。两者都没有绑定时，这次推断就没有世界书线索（其余来源照常）。

条目会被去重、跳过停用项，并按 `线索总字数上限`（默认 6000）截断。

### 模型返回的形状

```json
{
  "era": "帝国历",
  "months": [30,30,30,31,31,31,30,30,30,31,31,31],
  "monthNames": ["春月","花月","风月","夏月","炎月","雨月","秋月","霜月","叶月","冬月","雪月","寒月"],
  "leap": { "every": 0, "skip": 0, "unless": 0, "month": 1 },
  "format": "{era}{year}年{monthName}{day}日",
  "startDate": { "year": 1247, "month": 8, "day": 7, "hour": 9, "minute": 0 },
  "confident": true,
  "reason": "世界书里提到了霜月"
}
```

- `confident: false` 表示模型觉得线索不足，界面会用黄色提示，让你自己判断要不要套用；
- 套用时会做合法性校验：日期超出当月天数会被夹到当月最后一天，月名数量多于月份数会被截断；
- 勾了「推断成功后直接套用」就一步到位，否则先给预览。

### 安全边界

- 推断**只读**世界书 / 角色卡 / 对话，**不写**任何东西；
- 只在你点「开始推断」时才发请求；
- 套用是**你确认之后**才发生的（除非你自己勾了自动套用）；
- 事后可以随时用设置面板改回去，或者切换到别的档案。

## 常见问题

**Q：我切了角色卡，但时间轴没跟着换？**
时间轴（进行中的事件、剧情时钟）是**跟着聊天记录走**的，每场聊天各自独立。
配置档案管的是「怎么解析 / 怎么显示 / 用哪个提示词」。
所以换角色卡时，配置会切换，而新角色卡的聊天本身是空的——这是对的。

**Q：档案会不会把聊天数据也一起换掉？**
不会。档案只存设置；事件与时钟存在 `chat_metadata`，两者互不干扰。

**Q：我改设置改错了，怎么恢复？**
选回「全局默认」档案、或者切到对应的档案，改回来即可。
设置面板底部的「导出设置」可以把当前配置存成 JSON 备份。

**Q：AI 推断出来的历法不对怎么办？**
不勾「直接套用」，先看预览再手动改；或者只勾「月名」这一项套用，其余自己填。
模型看不到你世界书里的东西时（没绑定），它只能靠对话猜，结果会很保守。
